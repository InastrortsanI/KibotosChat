# 코드 설명서

🆕 표시는 처음 나오는 개념입니다. C#·Unity와 비교할 수 있는 부분은 함께 적었습니다.

## 1. 전체 구조: 메시지 하나가 처리되는 길

```
[브라우저 app.js]  "호시노, 낮잠 자?" 입력
   │  fetch POST /api/rooms/3/messages   (헤더: Authorization: Bearer 토큰)
   ▼
[routers/chats.py] send_message()
   ├─ security.current_user()  토큰으로 로그인한 유저 확인
   ├─ _own_room()              내 방이 맞는지 확인
   ├─ Message(user) 저장
   └─ _generate()
        ├─ memory.get_bonds()        학생별 호감도·기억 불러오기
        ├─ prompts.build_system_prompt()  세계관+학교+학생+관계+상황 → 긴 지시문
        ├─ llm provider.generate()   Gemini/Claude/OpenAI 중 선택된 API 호출
        ├─ memory.split_affection()  응답 끝의 [호감도 hoshino:+1] 떼어 내기
        ├─ memory.apply_affection()  호감도 반영 (0~100으로 제한)
        ├─ memory.maybe_summarize()  30개가 넘으면 오래된 대화를 요약
        └─ DB commit → JSON 응답
   ▼
[app.js] runTurn()  응답을 지문/대사로 나눠 그리고, 헤일로 링을 갱신
```

백엔드 게임 서버와 같은 구조입니다. **클라이언트는 화면만, 서버는 규칙과 저장을 책임집니다.**
호감도 계산을 서버에서 하는 이유는 클라이언트를 믿으면 조작이 가능하기 때문입니다 (게임 서버에서 재화를 서버가 관리하는 것과 같은 원리).

## 2. 파일별 핵심 개념

### `app/main.py` — 🆕 FastAPI 앱과 라우터
- `app.include_router(...)`: URL 묶음(라우터)을 앱에 붙입니다. Unity에서 씬에 오브젝트를 추가하듯, 기능별 파일을 조립합니다.
- `app.mount("/static", StaticFiles(...))`: `frontend/` 폴더 파일을 그대로 내려줍니다.

### `app/config.py` — 🆕 `@dataclass(frozen=True)`
- 필드만 적으면 생성자를 자동으로 만들어 주는 클래스입니다. `frozen=True`는 C#의 `readonly`처럼 값을 못 바꾸게 합니다.
- 비밀 값(API 키)은 코드에 쓰지 않고 `.env`에서 읽습니다.

### `app/db.py`, `app/models.py` — 🆕 SQLAlchemy ORM
- ORM은 **DB 테이블 ↔ 파이썬 클래스**를 연결합니다. C#의 Entity Framework와 같은 개념입니다.
- `Mapped[int] = mapped_column(...)`: 이 속성이 DB 컬럼이라는 선언입니다.
- `relationship(...)`: `room.messages`처럼 연결된 행을 리스트로 다룰 수 있게 합니다.
- 테이블 설계 포인트
  - `Bond`(관계)는 **유저+학생** 조합마다 한 줄 (`UniqueConstraint`). 그래서 방을 지워도 호감도는 남습니다.
  - `Message.affection`에 이번 응답의 호감도 변화량을 저장해서, '다시 생성'이나 '되돌리기' 때 정확히 원상복구합니다.

### `app/security.py` — 🆕 비밀번호 해싱, 토큰 인증
- 비밀번호는 절대 그대로 저장하지 않습니다. `pbkdf2_hmac`로 20만 번 해싱하고, 사람마다 다른 **솔트(salt)**를 섞어 같은 비밀번호도 다른 값이 되게 합니다.
- 로그인하면 무작위 토큰을 발급하고, 이후 요청은 헤더에 이 토큰을 붙여 보냅니다.
- 🆕 `Depends(current_user)`: **의존성 주입**. 함수 인자에 적어 두면 FastAPI가 요청마다 자동으로 실행해 결과를 넣어 줍니다. 로그인 검사를 엔드포인트마다 복사할 필요가 없습니다.

### `app/schemas.py` — 🆕 Pydantic
- 요청 데이터의 모양을 선언하면 FastAPI가 자동으로 검사합니다. 예: `Field(min_length=6)`이면 6자 미만 비밀번호는 함수에 들어오기 전에 거절됩니다.
- `Literal["single", "story"]`: 이 두 값만 허용 (C#의 enum과 비슷).

### `app/llm/` — 🆕 추상 클래스(ABC)와 팩토리
- `LLMProvider`는 C#의 `abstract class`/`interface`와 같습니다. `generate()`만 구현하면 어떤 회사 API든 끼울 수 있습니다.
- 라우터는 `get_provider("gemini")`로 받은 객체의 `generate()`만 호출하므로, **모델을 바꿔도 다른 코드는 한 줄도 안 바뀝니다.** 이것이 '교체 가능한 설계'입니다.
- 🆕 `async`/`await`: AI 응답을 기다리는 몇 초 동안 서버가 멈추지 않고 다른 유저 요청을 처리합니다. Unity의 코루틴(`yield return`)과 비슷한 발상입니다.
- `normalize()`: API들이 공통으로 요구하는 규칙(첫 메시지는 user, 역할 번갈아)을 한곳에서 맞춥니다.

### `app/prompts.py` — 대화 품질의 핵심
- 시스템 프롬프트를 **세계관 → 학교 → 학생 → 관계 단계 → 상황 → 출력 규칙** 순서로 조립합니다.
- 호감도 수치를 그대로 주지 않고 `STAGES`로 '행동 지침'으로 바꿔 줍니다. AI는 숫자보다 문장 지시를 더 잘 따르기 때문입니다.
- 출력 형식(`*지문*`, `이름: "대사"`)을 고정해서 프론트가 말풍선으로 그릴 수 있게 합니다.
- 학생들은 미성년자이므로 연애·성적 묘사를 금지하는 규칙이 들어 있습니다. 호감도는 '선생님에 대한 신뢰'로만 표현됩니다.

### `app/memory.py` — 🆕 정규표현식, 요약 기억
- `re.compile(r"\[호감도\s+([\w*]+)\s*:\s*([+-]?\d+)\]")`: `[호감도 hoshino:+1]` 같은 패턴을 찾아 학생 id와 숫자를 꺼냅니다. `( )` 안이 꺼내는 부분입니다.
- AI가 말을 안 듣고 +10을 줘도 `max(-2, min(2, ...))`로 잘라 냅니다. **외부 입력은 항상 검증**하는 습관.
- 요약: AI가 한 번에 읽을 수 있는 분량(컨텍스트)에는 한계가 있어서, 오래된 대화는 짧은 줄거리로 압축하고 최근 12개만 원문으로 보냅니다.

### `app/lore.py` — 🆕 `@lru_cache`
- 함수 결과를 기억해 두는 데코레이터입니다. JSON 파일을 매 요청마다 읽지 않고 처음 한 번만 읽습니다.

### `frontend/app.js`
- 🆕 `fetch()`: 브라우저에서 서버 API를 부르는 함수. `api()` 함수 하나로 감싸서 토큰·오류 처리를 한곳에 모았습니다.
- 🆕 **XSS 방지 `esc()`**: AI 응답이나 유저 입력을 HTML에 넣기 전에 `<`, `>` 등을 바꿉니다. 안 하면 누군가 `<script>`를 넣어 다른 사람의 토큰을 훔칠 수 있습니다.
- `renderAssistant()`: 응답을 줄 단위로 보고 `*...*`는 지문, `이름: "..."`는 말풍선으로 그립니다.
- 헤일로 링은 CSS `conic-gradient`로 호감도 %만큼 원을 채웁니다 (`--pct` 변수).
